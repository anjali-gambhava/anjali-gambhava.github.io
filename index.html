#incidents-resolved

Real problems. Real solutions. All resolved.

RESOLVED P0 Security #INC-001
Zero-Trust GCP Deployer
Problem

CI/CD pipelines required long-lived service account keys stored in GitHub Secrets — a credential leak risk in every single pipeline run. One compromised secret = full GCP access.

Resolution

Built a reusable hub-and-spoke GitHub Actions engine using Workload Identity Federation (OIDC). Zero keys. Short-lived tokens. Trivy SARIF scan gate blocks vulnerable images before they reach Cloud Run. IAP-protected endpoints with zero public SA exposure.

GitHub Actions GCP WIF Cloud Run Trivy Terraform IAP

RESOLVED P1 Engineering Velocity #INC-002
PR Governance Engine
Problem

Unreviewed, unchecked code merging to main — a compliance and quality risk. No enforced review requirements, no CI gates, no PR size limits. Chaos at scale.

Resolution

Built a reusable GitHub Actions workflow enforcing mandatory code reviews, CI pass requirements, branch protection policies, and PR size limits. Plug-and-play for any repository in the org.

GitHub Actions YAML Branch Protection Reusable Workflows

NetVision — Network Traffic Analyzer

Resolution

Built a real-time network analysis and visualization tool with deep packet inspection, protocol filtering, traffic pattern analysis, and anomaly detection. Containerized and CI/CD'd for easy deployment.
